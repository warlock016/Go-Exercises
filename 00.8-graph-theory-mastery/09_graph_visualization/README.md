# Exercise 09: Graph Visualization

**Tier:** 2 (Application)
**Time:** 60 min
**Goal:** Create human-readable graph representations

## Functions

```go
func ToAdjacencyMatrix(graph map[int][]int) string
func ToASCII(graph map[int][]int) string
func TraceBFS(graph map[int][]int, start int) string  // Step-by-step output
func TraceDFS(graph map[int][]int, start int) string
```

## Key Concept

Visualization helps debug algorithms. Create ASCII art showing graph structure and traversal order.

Practice manually tracing BFS/DFS to build intuition.
