# Module 01: Go Fundamentals

**Prerequisites:** Completed diagnostic assessment
**Estimated Time:** 12-15 hours (Week 1-2)
**Exercises:** 17 progressive exercises

## Learning Objectives

By the end of this module, you will:
- Master Go's basic syntax and types
- Understand variables, constants, and type conversions
- Use control structures (if, for, switch) idiomatically
- Work confidently with basic operators
- Write clean, readable Go code
- Debug simple syntax errors independently

## Module Structure

### Tier 1: Introduction (Exercises 01-04)
**Focus:** Basic syntax, variables, simple operations
- Variables and declarations
- Basic types (int, float, string, bool)
- Simple arithmetic and string operations

### Tier 2: Application (Exercises 05-09)
**Focus:** Control flow, common patterns
- If/else conditionals
- For loops (all variants)
- Switch statements
- Type conversions

### Tier 3: Integration (Exercises 10-14)
**Focus:** Combining concepts, problem-solving
- Nested control structures
- Multiple conditions
- Pattern matching
- String manipulation

### Tier 4: Mastery (Exercises 15-17)
**Focus:** Idiomatic Go, edge cases
- Go idioms and conventions
- Efficient solutions
- Handling edge cases
- Code organization

## How to Use This Module

### 1. Start at Your Level
Based on your diagnostic results:
- **Strong fundamentals (>75%):** Start at Exercise 05
- **Some knowledge (50-75%):** Start at Exercise 03
- **New to basics (<50%):** Start at Exercise 01

### 2. Progress Through Exercises
- Read the README in each exercise directory
- Implement the function(s)
- Run tests: `go test -v`
- Get all tests passing
- Write your explanation (required!)

### 3. Explain Your Code
After completing each exercise, create `EXPLANATION.md` in that directory:
- What does your code do? (line by line)
- Why did you choose this approach?
- What alternatives did you consider?
- What did you learn?

### 4. Track Your Progress
Update the progress file after each exercise:
```bash
# From this directory
cat progress.txt
```
