# Kanban Board Service

## Project Goal

Deploy a Kanban Board service that is accessible via public URL. The public URL is protected via Cloudflare Login Wall. The service provides a backend, a frontend and an API. The service stores kanban board state and card data persistently, across service restarts. The service is designed in a modular fashion to allow future extensibility. The frontend serves an interactive kanban board UI. The backend serves API endpoints to query and mutate persistent kanban board data.
